# 应急处理

## 需要马上处理时

遇到人身安全或医疗急症，先联系当地紧急服务，再联系学校公开的保卫、医疗入口。不要等待本站更新，也不要把紧急求助发到Issue或评论区。

## 可以收录的内容

- 校内医疗点、保卫部门和公开值班入口；
- AED、药箱、失物招领和校园安全设施的位置；
- 网络、门禁、宿舍设施等常见故障的官方报修渠道；
- 学校公开的心理支持和危机干预入口。

每条信息都要写清位置、适用时间、公开联系方式、来源和最近核验日期。涉及个人经历的内容要单独标为经验，不能替代学校的应急流程。

::: danger 紧急情况
遇到人身安全或医疗急症，请立即联系当地紧急服务和学校保卫部门，不要等待本页面更新。
:::

目前不在没有官方来源的情况下填写校内电话、位置和流程。发现紧急入口变更时，请提交新的官方页面或公告。
