# ☎️联系与办事

遇到具体事务，先按事项找到负责部门，再从部门官网确认电话、邮箱、办公地点和当前通知。

## 常用联系入口

- [学校官网](https://www.shou.edu.cn/)：查找学校通知和各部门网站。
- [教务处](https://jwc.shou.edu.cn/)：课程、选课、考试、成绩、学籍、培养方案和毕业相关事务。
- [学生在线](https://xszx.shou.edu.cn/)：学生教育管理、资助、心理健康、就业创业和办事指南。
- [后勤管理处](https://hqc.shou.edu.cn/)：宿舍、餐饮、医疗、能源、维修和失物招领等后勤信息。
- [图书馆](https://library.shou.edu.cn/)：借阅、数据库、阅览室和图书馆服务。
- [现代信息与教育技术中心](https://xjzx.shou.edu.cn/)：校园网络、邮件、一卡通和信息系统支持。

## 查找顺序

1. 先确认事情属于哪个部门，以及对应的校区。
2. 打开部门官网，查看最新通知或“联系我们”页面。
3. 联系前记下事项名称、截止日期和已经遇到的问题。
4. 需要提交材料时，保留提交记录或回执。

电话、邮箱、办公时间和办理地点可能调整。页面只收录公开联系方式，不收录个人手机号、私人邮箱或内部群二维码。

::: warning 信息时效
联系方式和办事入口以学校及各部门最新页面为准。发现失效链接时，请附新的官方页面提交修订。
:::
