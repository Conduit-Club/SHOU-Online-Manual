# 自驾到校

上海海洋大学临港校区地址为**上海市浦东新区南汇新城镇沪城环路 999 号**。从上海市区或外省市驾车前往学校，可以参考 **S2 沪芦高速 → 申港大道出口 → 沪城环路**，经过橄榄路后前往学校 1 号门。

路线文档给出的路线适合作为导航起点，实际入校校门、停车位置和临时交通组织仍要以当次报到通知和现场指引为准。导航终点建议填写“上海海洋大学临港校区”或具体校门，不要只搜索“海洋大学”。

## 外省市号牌车辆

外省市号牌和临时号牌车辆进入上海市区前，应先查询当天的限行范围、时段和例外情况。上海的限行规则会调整，不能只按旧攻略里的时间安排路线。

可以通过[上海市人民政府发布的道路限行通告](https://www.shanghai.gov.cn/nw12344/20210425/3d689cc0aab947598c4504c6e988801d.html)了解规则，再通过“随申办”App中的“上海交警－车辆限行查询”核对当天信息。出发前还要查看导航给出的路线是否经过受限高架或内环地面道路。

## 到校前留出什么时间

- 高速出口、申港大道和沪城环路的道路状况会影响最后一段用时；
- 报到日可能有临时停车、落客和入校安排，车辆能否进入校园以现场指引为准；
- 行李装卸、找校门和从停车点步行到报到点都需要时间；
- 如果车辆不能直接到达报到点，提前和同行人约定落客位置，减少在校门口反复绕行。
