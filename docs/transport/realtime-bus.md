# 公交实时位置接入评估

> 评估日期：2026-09-10

本页评估在手册中展示 **1077 路、1043 路、临港中运量 1 号线和 2 号线**实时车辆位置的可行性。当前结论是：**仅使用高德地图 API，不能可靠实现截图中的车辆实时点位；需要接入公交运营方或上海出行即服务（随申行）的授权数据，并增加服务端代理。**

## 已确认的数据能力

### 高德地图 API

高德官方公交信息查询接口可以查询公交站、公交线路和线路详情。线路数据包含线路 polyline、途经站点、首末班时间等信息，适合绘制静态线路和站点；官方返回字段没有在途车辆的经纬度、车辆编号或实时轨迹。

- [高德公交信息查询 API](https://lbs.amap.com/api/webservice/guide/api-advanced/bus-inquiry)
- [高德 Android 地图 SDK 公交数据说明](https://lbs.amap.com/api/android-sdk/guide/map-data/bus)

因此，不能把高德返回的线路 polyline 当作车辆位置，也不应根据线路几何形状自行移动一个“公交车”图标并标记为实时。

### 随申行开放平台

随申行的公共交通接口更接近本需求：

- 查询公交路线：返回线路、站点 GPS 坐标，以及指定站点的最近车辆距离、预计到站时间和剩余站数；
- 查询公交到站详情：返回指定站点最近一辆和下一辆车的到站信息；
- 文档没有提供可直接绘制车辆点位的车辆经纬度字段。

接口接入还要求平台通过邮件提供域名、商户编号和盐值，并要求调用方提供固定出口 IP 进行白名单校验。请求需要服务端使用签名请求头，不能把盐值或商户凭证放进 VuePress 浏览器端。

- [随申行公共交通服务](https://open-web.shmaas.cn/docs/category/公共交通服务/)
- [查询公交路线](https://open-web.shmaas.cn/docs/public-traffic/查询公交路线/)
- [查询公交到站详情](https://open-web.shmaas.cn/docs/public-traffic/查询公交到站详情/)
- [随申行接入网关](https://open-web.shmaas.cn/docs/guide/)

## 对目标线路的判断

| 线路              | 线路静态信息 | 站点到站信息             | 车辆地图点位                  |
| ----------------- | ------------ | ------------------------ | ----------------------------- |
| 1077 路           | 可查询或配置 | 需确认随申行线路数据覆盖 | 需要运营方 GPS 或专用授权接口 |
| 1043 路           | 可查询或配置 | 需确认随申行线路数据覆盖 | 需要运营方 GPS 或专用授权接口 |
| 临港中运量 1 号线 | 可查询或配置 | 需确认随申行线路数据覆盖 | 需要运营方 GPS 或专用授权接口 |
| 临港中运量 2 号线 | 可查询或配置 | 需确认随申行线路数据覆盖 | 需要运营方 GPS 或专用授权接口 |

“可查询或配置”不代表当前已经核验了每条线路的实时覆盖。正式上线前，需要用当天的 `cityCode`、`lineId`、方向和站点编号逐条联调，并记录接口返回时间和覆盖范围。

## 推荐的接入方案

### 第一阶段：到站信息

由服务端代理随申行接口，浏览器只请求本站的同源接口，例如：

```text
GET /api/transport/arrivals?line=1077&stop=沪城环路橄榄路&direction=0
```

服务端负责保存凭证、生成签名、限制请求频率、缓存短时结果，并只返回页面需要的字段。前端可以展示“最近一班车约 X 分钟到站、还有 Y 站”，这部分与随申行公开文档的字段相匹配。

### 第二阶段：车辆地图点位

只有在取得运营方或数据平台提供的车辆经纬度、坐标系、更新时间、线路和方向字段后，才在现有 `CampusMap` 的 MapLibre 图层上增加车辆标记。接口至少需要类似以下数据：

```json
{
  "line": "1077",
  "vehicleId": "redacted",
  "direction": "up",
  "location": [121.89284, 30.88462],
  "updatedAt": "2026-09-10T14:09:00+08:00"
}
```

数据超过允许的新鲜度后，地图应隐藏或降级标记，不能继续显示为实时位置。还需要确认高德 GCJ-02、GPS/WGS84 和 MapLibre 使用坐标之间的转换要求。

## 当前不做的事情

- 不在前端暴露高德 Key、随申行商户编号、盐值或签名逻辑；
- 不把静态线路 polyline 或站点位置伪装成车辆实时位置；
- 不在没有接口覆盖证明的情况下承诺 1077 路、1043 路、中运量 1/2 号线都能显示实时车辆；
- 不引入轮询空接口或演示用假车辆点位。

## 进入开发的前置条件

1. 确认目标线路由哪家运营方提供车辆 GPS 数据，并取得书面授权或正式接口文档。
2. 确认接口覆盖四条线路、上下行、车辆更新时间和坐标系。
3. 提供可部署的服务端运行位置、固定出口 IP、密钥存储方式和请求限额。
4. 先以“站点到站信息”做小范围联调，再评估是否增加车辆地图点位。
