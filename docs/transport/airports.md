# 机场到校

到校地址为**沪城环路999号**。先确认落地的是浦东机场还是虹桥机场，以及航站楼是T1还是T2。

## 先选方案

| 落地地点        | 可以怎样走                                                        | 适合先查什么                         |
| --------------- | ----------------------------------------------------------------- | ------------------------------------ |
| 浦东机场T1 / T2 | 临港DZ38线 → 临港大道 → 1077路                                    | 班次少，先确认时间和预约情况         |
| 浦东机场T1 / T2 | 机场八线 → 惠南 → 16号线 → 临港大道 → 1077路                      | 先查机场八线还有多久来               |
| 浦东机场T1 / T2 | 2号线 → 龙阳路 → 16号线 → 临港大道 → 1077路                       | 地铁换乘清楚，但先往市区走，路线较绕 |
| 虹桥机场T2      | 2号线 → 龙阳路 → 16号线 → 临港大道 → 1077路                       | 直接找2号线进站                      |
| 虹桥机场T1      | 10号线 → 虹桥火车站 → 2号线 → 龙阳路 → 16号线 → 临港大道 → 1077路 | T1没有2号线，先乘10号线              |

上述路线到达临港大道后，都可按[临港大道站到学校](./README.md#临港大道站到学校)乘**1077路**，在**沪城环路橄榄路**下车。到哪个校门、如何进入报到点，以学校当次通知为准。[学校交通指引](https://zsjy.shou.edu.cn/13863/list.htm)

地铁段：**龙阳路 → 临港大道**大站车约**43分钟**，普通车约**1小时**；**惠南 → 临港大道**普通车约**20–22分钟**。临港大道接1077路到校门附近，车上约**10–20分钟**，候车和步行另计。[地铁首末班与区间时间](./README.md#16-号线首末班) · [地铁网络图](./README.md#上海地铁网络图)

## 浦东机场：先看直达临港的班次

### 临港DZ38线：能赶上时少换乘

从T1 / T2的机场巴士乘车点乘**临港DZ38线，滴水湖枢纽站方向**，在中途的**临港大道沪城环路（临港大道地铁）**下车，再接1077路到校。

机场至临港方向的固定发车信息如下。

| 上车航站楼 | 官网列出的固定班次 | 公交票价 |
| ---------- | ------------------ | -------- |
| 浦东T2     | 08:00、18:30       | 20元     |
| 浦东T1     | 08:05、18:35       | 20元     |

这条线不能随到随走。官网提示可在**“临港出行”小程序**查询预约班次，咨询电话为**021-60829566**。出发前确认具体日期、方向和上车点；落地后还需提取行李，不宜按飞机落地时刻卡着发车时间安排。[来源：上海机场地面交通](https://www.shanghaiairport.com/dmjt/index.html)

### 机场八线：经惠南接16号线

| 上车点 | 首班  | 末班  | 发车间隔                     |
| ------ | ----- | ----- | ---------------------------- |
| 浦东T1 | 07:00 | 20:40 | 高峰15–60分钟，平峰15–90分钟 |
| 浦东T2 | 07:03 | 20:43 | 高峰15–60分钟，平峰15–90分钟 |

时刻与间隔来自[上海机场地面交通表（2026-06-01更新）](https://www.shanghaiairport.com/dmjt/index.html)。

1. 在机场巴士站乘**机场八线，南汇汽车站方向**。
2. 在**南祝路拱极路**下车，按导航步行至地铁**惠南站**；不要坐到汽车站终点才找地铁。
3. 乘**16号线，滴水湖方向**，在**临港大道**下车。
4. 换1077路，在**沪城环路橄榄路**下车后前往校门。

**南祝路拱极路**是换乘惠南站的下车点，乘车时可提前向司机确认。[机场线路表](https://www.shanghaiairport.com/dmjt/index.html)、[学校换乘指引](https://yjs.shou.edu.cn/2018/0901/c14023a254566/page.htm)

机场八线沿途停站较多，等车和道路情况会影响时间。先查实时到站，再与地铁方案比较，不能简单认为公交一定更快。

### 地铁方案：2号线接16号线

1. 按航站楼的地铁标识到**浦东1号2号航站楼站**，乘**2号线往市区方向（蟠祥路·国家会计学院方向）**。
2. 在**龙阳路**下车，按站内指引换**16号线，滴水湖方向**。
3. 在**临港大道**下车，接1077路到校。

浦东T1 / T2均可按航站楼内标识前往2号线。到龙阳路后无需出闸，跟随**16号线**换乘标识走到站台，再确认**滴水湖方向**。[机场轨道交通](https://www.shanghaiairport.com/gdjt/index.html)、[2号线线路说明](https://jtw.sh.gov.cn/xwfb2/20251027/14557ac7aeaa4e95a61cce023ce01a55.html)

## 虹桥机场：区分T1和T2

### T2到校

到**虹桥2号航站楼站**乘**2号线，浦东1号2号航站楼方向**，在**龙阳路**换**16号线，滴水湖方向**，到**临港大道**接1077路。无需先走到铁路上海虹桥站。

### T1到校

到**虹桥1号航站楼站**乘**10号线，虹桥火车站方向**，到终点**虹桥火车站**后按指引换**2号线，浦东1号2号航站楼方向**。之后在**龙阳路**换16号线，到**临港大道**接1077路。

10号线从T1依次经过**虹桥2号航站楼、虹桥火车站**。到虹桥火车站后站内换乘2号线，再按[虹桥火车站到校路线](./railway-stations.md#上海虹桥站到校)乘车。[机场轨道交通说明](https://www.shanghaiairport.com/hongqiao/gdjt/index.html)

## 机场联络线能不能直接去学校

**不能直接到校，也没有与16号线的直接换乘站。**机场联络线与2号线是不同线路；官方乘车说明列出的地铁换乘涉及2、9、10、15、17号线和磁浮，未列出康桥东与16号线换乘。不要把“机场联络线到康桥东”接上一段想当然的16号线换乘。[来源：上海国际服务门户乘车说明（更新于2026-03-31）](https://english.shanghai.gov.cn/en-Transportation/20241231/f66f14bbd4b549ab88e6f3aec375790c.html)

如果导航提出机场联络线方案，需看清其后是否还要转其他地铁、公交或网约车，并比较总票价与总时间，而不是只比较机场联络线这一段。

## 晚到与返程

航班落地时间不等于走出航站楼的时间。晚到时同时检查机场交通、16号线和1077路能否衔接；机场夜间仍有巴士，不代表还能通过龙阳路换乘到学校。机场公布的守航夜宵线是去市区及虹桥方向，不能当作临港夜班车。[机场地面交通](https://www.shanghaiairport.com/dmjt/index.html)

从学校去机场时重新按**出发日期、航站楼、航司要求到达的时间**查询返程；不要把DZ38线的机场出发时刻倒过来用。来回方向的道路、站台、公交班次与候车时间均可能不同。
