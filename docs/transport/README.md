# 交通

本页用于整理上海海洋大学的校车、公交、地铁、铁路和机场出行信息。

::: warning 待核验
交通时刻表和线路变化较快，请以运营方和学校最新通知为准。
:::

## 地铁

从上海市区前往学校，常见路线是在[龙阳路站](https://www.shmetro.com/)换乘地铁 16 号线，乘坐至**临港大道站**，再根据学校所在位置换乘公交或步行前往。

::: tip 出行提示
从龙阳路站出发的16号线一般是周期性发车，车到了后不一定立即出发。
此外，16号线有普通车与大站车之区分。大站车时间一般稳定在42分钟上下能抵达临港大道，而普通车因每站停靠则是45分钟到1小时不等。
大站车一般需要略早于整点抵达才可赶上，较晚时即便赶上也难以寻找到座位。
具体换乘站、首末班车和校内接驳安排可能变化，请先行参考公交小程序等。
:::
