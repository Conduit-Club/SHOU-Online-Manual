# 媒体与网站

查学校新闻、找学院通知和办理业务，可以从下面的公开入口开始。**官方入口整理：2026-09-14；外部评价整理：2026-09-15。**

## 上海海洋大学官方媒体

| 入口                                       | 适合查什么                             | 如何确认来源                   |
| ------------------------------------------ | -------------------------------------- | ------------------------------ |
| [学校官网](https://www.shou.edu.cn/)       | 学校新闻、公告、院系部门与常用站点     | 从官网导航进入对应栏目         |
| 微信公众号“上海海洋大学”                   | 学校新闻、校园活动与专题推送           | 通过学校官网页脚“微信”入口关注 |
| [学校官方微博](https://weibo.com/shou1912) | 学校动态与活动信息                     | 学校官网页脚“新浪微博”链接     |
| [党委宣传部网站](https://xcb.shou.edu.cn/) | 新闻宣传、校园文化与新媒体相关公开资料 | 与学校官网“文明在线”入口对应   |

[学校 2024 年宣传工作报道](https://www.shou.edu.cn/2024/0619/c147a331983/page.htm)介绍了微信、微博、哔哩哔哩、快手、抖音等平台建设情况，其他平台的当前账号链接待补充。

微信公众号适合看推送；选课、报名、缴费和材料提交仍要打开通知所指的主管部门原文，核对适用年级与截止日期。

**安静环境与通勤的取舍：** 职朋金融学留言（2018 级，2022-01-20）认可安静环境，也担心市区体验与跨校交流的便利性；海洋渔业科学与技术留言（2015 级，2022-07-12）提到市区实习、辅修的通勤负担。计划经常进城时，可以结合自己的目的地、课表和出行时段查看[交通方案](/transport/)。

**同一设施也有不同感受：** 生活质量指北的餐饮回答中，A27949（2025-05）认为便宜，A30676（2025-06）觉得贵；床型、卫浴是否“独立”的回答也不完全一致。当前页最新回答为 **2026-06**，[第二批宿舍维修](https://hqc.shou.edu.cn/2026/0621/c18828a353832/page.htm)后的入住条件请向自己小区确认。服务查询见[校园设施](/facilities/)和[饮食](/canteen/)。

### 校园故事：一次科研启蒙的回忆

小宇宙节目“未折春”的[《大学里的我们来去匆匆，来不及道别也没来得及道谢》](https://www.xiaoyuzhoufm.com/episode/662bd408cf9ec69c6c84a99e)有公开文字，发布于 **2024-04-27（北京时间）**。作者回忆在海大通过小型创新项目接触生态学研究，并受到导师、同学和社团前辈的支持，分享了课堂以外的成长经历。

### 满意度数字怎么读

软科高校页的 **2025 年调查摘要**将“教师注重与学生互动”的“满意及以上比例”列为 **60%—65%**，对应参与调查者对这一项目的评价。公开摘要未展示海大样本量及专业分布；调查说明见[软科报告介绍（2025-07-23）](https://www.shanghairanking.cn/report/18_2025)。
