# 新生指南

[[toc]]

## 新生做什么

在入学之前，新生需要准备好相应的材料。视学院与专业不同，可能存在细微差距。但通常情况下，你的身份证、手机、录取通知书是必须携带的。同时，切记不要忘记其他在录取通知文件夹中资料所提及的材料。

## 入学前

- 查看[本科生招生网](https://zsjy.shou.edu.cn/)或[研究生招生网](https://yjs.shou.edu.cn/)发布的录取和报到通知。
- 确认报到日期、交通方式和通知要求携带的材料。
- 保存招生部门、学院和辅导员提供的官方咨询入口。

## 到校交通

机场、火车站、临港大道地铁站和自驾到校的长期路线，统一放在[交通栏目](/transport/)维护。第一次到校可以先看[临港大道站到学校](/transport/#临港大道站到学校)，需要按机场或车站查路线时，直接进入交通栏目中的对应页面。

地铁、公交线路和临时交通安排可能变化，出发前应使用随申行、地图软件和当年迎新通知核对。机场和火车站路线还要给行李、换乘、安检和步行留出时间。

2026 年迎新期间，学校安排过临港大道地铁站到校内各停车点的免费接驳车，运行时间为 2026-09-15 8:00—17:00，发车间隔约 30 分钟，预约截止时间为 2026-09-12 12:00。这个安排属于当年迎新专属接驳，后续年份不能直接沿用，是否开放应以当年迎新通知为准。

## 到校报到

到达临港校区后，按当年招生通知确认报到地点和现场流程。交通路线只能帮助你到校，宿舍入住、校园卡、材料提交和迎新点位置仍要以学院或学校当年的通知为准。

到校前可以把下面几项准备好：

- 保存录取通知、报到通知和学院提供的联系人信息；
- 提前确认自己要到哪个校区、哪个报到点，避免把临港校区和其他校区混淆；
- 把学校地址和宿舍信息留在手机里，行李较多时也可以提前准备截图；
- 到现场后按指引完成报到，涉及材料提交、宿舍入住或物品领取时保留回执和现场说明；
- 如果晚到、路线临时变化或找不到报到点，先联系学院、辅导员或迎新志愿者。

## 报到后的办理

- 记录宿舍、校园卡、网络和餐饮服务的办理入口。
- 需要提交材料或领取物品时，保留回执和现场指引。

## 开学后

- 从[海大常用入口总览](/service/official-entrances.html)进入数字校园、邮件、教务处和图书馆。
- 在[教务处](https://jwc.shou.edu.cn/)查看校历、课表、考试安排、培养方案和学生教务入口。
- 在[后勤管理处](https://hqc.shou.edu.cn/)查找宿舍、维修、餐饮和其他后勤服务。

## 写给新生的提醒

招生年份、缴费方式、住宿信息和报到流程都可能变化。旧攻略可以帮助理解流程，但不能直接替代当年的官方通知。

::: warning 信息时效
本页只保留跨年份仍然有用的查找方法。具体日期、费用、材料和入口按招生季更新，并以学校当年通知为准。
:::
