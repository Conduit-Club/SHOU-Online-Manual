# 新生指南

新生入学后会反复用到几类入口：招生通知、报到安排、数字校园、教务系统、校园卡和后勤服务。本页按入学前、报到时和开学后整理，具体日期和材料仍以当年通知为准。

## 入学前

- 查看[本科生招生网](https://zsjy.shou.edu.cn/)或[研究生招生网](https://yjs.shou.edu.cn/)发布的录取和报到通知。
- 确认报到日期、交通方式和通知要求携带的材料。
- 保存招生部门、学院和辅导员提供的官方咨询入口。

## 报到时

- 按通知确认报到地点和现场流程。
- 记录宿舍、校园卡、网络和餐饮服务的办理入口。
- 需要提交材料或领取物品时，保留回执和现场指引。

## 开学后

- 从[海大常用入口总览](/service/official-entrances.html)进入数字校园、邮件、教务处和图书馆。
- 在[教务处](https://jwc.shou.edu.cn/)查看校历、课表、考试安排、培养方案和学生教务入口。
- 在[后勤管理处](https://hqc.shou.edu.cn/)查找宿舍、维修、餐饮和其他后勤服务。

## 写给新生的提醒

招生年份、缴费方式、住宿信息和报到流程都可能变化。旧攻略可以帮助理解流程，但不能直接替代当年的官方通知。

::: warning 信息时效
本页只保留跨年份仍然有用的查找方法。具体日期、费用、材料和入口按招生季更新，并以学校当年通知为准。
:::
