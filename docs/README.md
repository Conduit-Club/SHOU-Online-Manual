# 📚水专手册

面向上海海洋大学 SHOUer 的校园信息手册。

::: warning 建设中
本站正在从南科大手册迁移为上海海洋大学版本。当前各栏目以待核验的占位页为主，请勿把未标注来源的内容用于办理事务。
:::

## 使用手册

从侧边栏进入新生、学习、服务、生活、设施、交通、联系和应急等栏目。每个栏目会按校区、适用学年和来源持续更新。

## 提交信息前请确认

校内政策和服务变化较快。提交电话、地址、流程、时间表或系统链接时，请附官方来源和核验日期；个人经验请注明适用学年。遇到紧急情况，请以学校官方渠道和当地紧急服务为准。
