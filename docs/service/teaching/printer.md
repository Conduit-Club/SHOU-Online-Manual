# 校园自助打印

## 去哪里打印

下表按 **2024 年学生会指南**整理，装修后是否搬动、现在能不能用，还需要在校同学确认。最近整理：2026-09-16。

| 地点           | 怎么找                                           |
| -------------- | ------------------------------------------------ |
| 第一教学楼     | 找到 **1114 门牌**，看看旁边的走廊               |
| 第二教学楼     | 找到 **2105 门牌**，看看旁边的走廊               |
| 第三教学楼     | 在走廊里找饮料售货机，打印机在旁边               |
| 第四教学楼     | 找大窗旁的公共区域，打印机靠墙放，旁边有黄色电话 |
| 图书馆         | 旧指南记在一楼打印室，具体入口待确认             |
| 第一餐厅       | 找到 **海洋大学邮政所**，打印机在门口旁          |
| 大学生活动中心 | 大厅里，具体入口和楼层待同学补充                 |

[2024 年学生会指南](https://mp.weixin.qq.com/s/0QhoBPAI7mtPc02_eUEwRQ)里有各处实景图。图书馆「一楼打印室」的说法来自下方的 2022 年指南。

**爱恩学院**： 2022 年指南还提到学生团委学生会办公室旁有打印机，现在是否保留待确认。

**研究生区别再去原罗森找**： 原罗森已经撤了，换成的 7-11 里也没有打印机（2026-09-14 同学反馈）。

## 怎么打印

不同机器的上传入口和操作界面可能不同，到机器前先看屏幕和旁边的操作说明。

1. **选文件**： 用机器给出的上传入口选择文件；需要扫码时，扫机身或屏幕上的二维码。
2. **选打印方式**： 看清要印哪些页、几份、黑白还是彩色、单面还是双面，再检查预览有没有漏页或排版错误。
3. **看总价再付款**： 确认金额和打印设置后，按屏幕提示支付。
4. **取走材料**： 拿齐打印件；复印时别忘了扫描台上的原件，离开前退出登录。

当前小程序名称、支持的文件格式和价目表还没收集齐，以机器显示为准。

**要打证件照？** 2022 年指南记录过图书馆的一寸、二寸证件照和五寸照片打印。到场先确认设备仍支持，别在普通文档打印机上直接下单。

## 付了钱却没打印出来怎么办

先保存订单和付款截图，记下机器位置、出错时间，再找机身贴着的客服。缺纸、卡纸也可以按这个方式报修；找不到客服时，问旁边的工作人员。还没弄清原因前，别重复付款。

想问**文印室**的位置和营业时间，可拨打[资产经营公司咨询电话](https://zcgs.shou.edu.cn/15740/list.htm)：**021-61900300**（2026-09-16 查阅）。自助机的订单问题先找机身客服。

## 帮忙补充

如果你最近用过，欢迎到[打印机待办 #50](https://github.com/Conduit-Club/SHOU-Online-Manual/issues/50) 说说：从哪个门进去、上几楼、机器能不能用、怎么传文件、印一页多少钱。附上日期和机身价目表就更方便了，别拍进自己的文件或账号。
