# 校园自助打印

:::warning[适用范围与时效]
本文整理上海海洋大学临港校区自助打印点的历史线索和已知现状。设备是否可用、收费标准、支持的文件格式及支付方式可能调整，请以设备屏幕和现场公示为准。最近更新日期：2026-09-14。
:::

## 历史线索与现状

- **第一餐厅一楼：** 2024-11-18 的校学生会文章称，ATM 机旁设有自助打印机；该位置也靠近平信与报刊收发室。该信息尚缺少装修后来自学生的一手反馈，是否仍可使用未核实，前往前请先向现场确认。
- **研究生区：** 早期文章所述的罗森已不在；替代罗森的 7-11 内目前也没有打印机。因此不建议专程前往该区域寻找自助打印服务。

上述第一餐厅位置来自校学生会的历史通知；研究生区现状根据 2026-09-14 收到的维护者反馈更新。除已说明的地点外，校园内其他设备的当前分布仍请以现场为准。

## 使用前确认

1. 先在设备屏幕或机身二维码处确认文件上传、登录和支付方式。
2. 提交前检查预览页数、单双面、彩色或黑白等选项，以及屏幕显示的费用。
3. 打印完成后及时取走文件，并退出账号或删除设备中暂存的文件。

:::tip[材料与隐私]
身份证、成绩单、证书等含个人信息的材料，建议只在现场操作和取件；如需复印，先确认原件是否遗留在扫描台。
:::

## 遇到问题

设备缺纸、卡纸、扣费后未出纸或无法登录时，请保留订单、支付或错误提示的截图，并按设备机身标注的客服或维护渠道反馈。现场没有标注联系方式时，可向第一餐厅服务台询问。
