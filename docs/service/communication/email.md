# 电子邮件

本页介绍学校邮箱的进入方式、账号解锁和求助渠道。

## 从哪里进入

目前建议先登录[网上办事大厅](https://portal.shou.edu.cn/)，再点击其中的邮箱入口进入。学校官网另列有[邮件系统](https://mail.shou.edu.cn/)，但直接打开时可能无法正常登录。

:::info[管理员使用反馈 · 2026-09-15]
管理员 **LagrangeWithLight** 在[PR 审阅中反馈](https://github.com/Conduit-Club/SHOU-Online-Manual/pull/51#discussion_r4015516468)：在 **2025 学年一整年**的使用中，外部邮件客户端配置和邮箱独立改密持续失败，需要通过网上办事大厅内的邮箱入口使用。建议按上述门户路径收发邮件。
:::

## 长期未用，邮箱被锁定

现教中心于 **2025-12-18** 发布的[师生邮箱解锁说明](https://xjzx.shou.edu.cn/2024/0226/c12937a349347/page.htm)明确：长期不使用可能导致邮箱自动锁定。需要解锁时，在网上办事大厅搜索 **“校园电子邮件业务申请”**，进入流程提交申请。

如果能够进入办事大厅而无法使用邮箱，先查看是否提示锁定，再按上述流程处理，不要反复猜测密码。

## 密码和邮件客户端

- **办事大厅密码遗忘**：在登录页面点击“忘记密码”。未绑定安全手机或安全邮箱的学生，可联系辅导员通过“统一身份认证密码重置”流程申请。详见[官方密码找回说明](https://xjzx.shou.edu.cn/2019/1012/c12937a253582/page.htm)（页面日期 **2020-09-17**）。
- **邮箱自身密码或登录故障**：上述官方说明将邮件系统列为例外，不能假定重置办事大厅密码就一定会同步重置邮箱。联系现教中心确认当前处理方式。
- **外部邮件客户端或独立改密失败**：先使用门户内邮箱；确有客户端需求时向现教中心咨询当前配置。学校的[2020 年客户端说明](https://xjzx.shou.edu.cn/2020/1228/c12937a283071/page.htm)仅作旧文档参考，不能据此判断现在可正常使用。

邮箱使用问题可咨询现教中心：**021-61900245**；综合服务热线 **021-61900099**（[现教中心官网](https://xjzx.shou.edu.cn/)）。

如果你也尝试过第三方客户端或独立改密，欢迎在[本项目](https://github.com/Conduit-Club/SHOU-Online-Manual/issues)补充尝试日期、客户端名称、协议和成功或失败结果，截图请隐去账号与邮件内容。

## 公共邮箱与离校安排

学院、部门等单位申请业务邮箱时，应按[公共电子邮箱申请](https://xjzx.shou.edu.cn/2019/0428/c12950a243964/page.htm)填写申请单、指定责任人，经部门签字盖章后提交审核。

:::warning[仍需确认]
新生个人邮箱的开通安排、容量及毕业后的保留期限，请查看当年新生、离校通知或咨询现教中心。
:::

不要在公开 Issue、群聊或截图中提交密码、验证码、邮箱内信件或身份证信息。
