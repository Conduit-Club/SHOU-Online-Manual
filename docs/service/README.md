# 🧾校内服务

这里收集统一身份认证、教务、校园卡、网络、邮箱、打印和办事大厅等服务的入口与使用提示。

## 从哪里开始

先看[海大常用入口总览](./official-entrances.md)，按学习、学生事务、后勤和招生就业查找入口。

## 网络与信息服务

- [现代信息与教育技术中心](https://xjzx.shou.edu.cn/)：查看校园网络、邮件、一卡通和信息系统通知。
- [数字校园](https://portal.shou.edu.cn/)：从学校统一入口进入线上服务；登录后可见的服务以当前页面为准。
- [访客认证说明](https://xjzx.shou.edu.cn/2024/0305/c12937a326802/page.htm)：校内用户为访客申请临港校区无线网络时参考。

## 使用时记住三件事

- 从学校官网或对应部门官网进入，避免使用搜索结果中的旧链接。
- 页面打不开时，先确认网络环境、账号身份、校区和适用学年。
- 涉及提交、缴费或报名的操作，保存成功页面、回执或报错截图。

不同系统的登录方式和权限可能不同；本页提供入口，不替代系统页面和部门通知。
