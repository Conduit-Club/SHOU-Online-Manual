## 宿舍有线宽带

本科生宿舍提供家庭宽带服务，采用自建 FTTH（光纤到户）架构。

:::info[更新说明]
本节信息更新于 **2026-09-12**，来自社团群友提供的第一手体验。学校返修后网络架构已变化，宽带运营商已由联通切换至中国移动。
:::

### 硬件与接入

- **网口数量**：本科生宿舍配置四个网口，理论上可多人分别拉取宽带。
- **网线**：安装师傅可能会收走原有网线，换成新的网线。

### 认证与拨号

- **拨号方式**：现需使用学号进行拨号认证。

### 运营商与套餐

中国移动校园宽带提供三档套餐。所有套餐均包含 80GB 蜂窝流量、200 分钟通话、120 CNY 教育超市权益或热门 APP 会员权益任选其一：

| 套餐 | 年费    | 宽带速率               |
| ---- | ------- | ---------------------- |
| 基础 | 490 CNY | 仅蜂窝数据，无家庭宽带 |
| 标准 | 690 CNY | 300 Mbps               |
| 高速 | 890 CNY | 1000 Mbps              |

### 网络特性

- **网络类型**：自建 FTTH 校园宽带（家庭宽带）。
- **IPv6**：默认未配置，暂不清楚是否支持手动启用。
- **上传限制**：每月上传流量上限约 1 TB。
- **路由路径**：校内外流量可能分别走不同出口。学校似乎同时保留了移动和其他运营商的出口链路。

### 测速参考

**测试环境**：1000 Mbps 套餐，非完全高峰时段

- **USTC 测速站**：延迟 32 ms，抖动 76.5 ms，下载 984 Mbps，上传 119 Mbps
- **Steam 下载实测**：约 800 Mbps 出头，无法完全跑满理论带宽

### 已知限制

- **校内外访问**：实验室工作站的校外公网 IP 暂无法直接访问校内资源。校内需通过 EasyConnect VPN（移动线路）访问校外资源。

## 校外访问 VPN

校外使用校内公共资源时，可进入 [上海海洋大学 VPN](https://vpn.shou.edu.cn/)，通过学校统一身份认证登录。人脸采集的校外访问步骤见下方；账号或连接问题可通过[信息中心联系方式](/contact/#信息中心-网络、邮箱与信息系统)咨询。

来源：[2026 级新生报到指南](https://mp.weixin.qq.com/s/Ij-n7Y8YEUuHfKWTxkcUuA)；**2026-09-12** 按维护者提供的正文核对入口及认证方式，未测试登录或客户端配置。

### 人脸采集使用 EasyConnect

[新生入校与人脸采集操作指南](https://mp.weixin.qq.com/s/UdDRp1-35VbvNGGtSwkiew)说明，校外办理人脸采集时：

1. 按原文图文指引下载安装 **EasyConnect**，服务器地址填写 **vpn.shou.edu.cn**。
2. 使用学校统一身份认证账号和密码登录。首次使用须先激活账号，原文提供的[账号激活入口](http://authx-service.shou.edu.cn/active-account)为 `http://authx-service.shou.edu.cn/active-account`。
3. VPN 连接成功后，回到“上海海洋大学”公众号，选择 **我的海大 → 人脸采集**，按[人脸采集说明](/service/face-registration/)办理。

本节于 **2026-09-12** 按维护者提供的正文整理，已拼接原文换行拆开的激活网址；未测试账号激活、下载或登录。完整截图和下载方式请查看原文。
