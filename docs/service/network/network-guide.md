# 校园网络

- [校园无线网络](/service/network/campus-network.html)
- [宿舍有线宽带](/service/network/campus-broadband.html)

适用对象：本校师生，以及经校内用户授权的访客。最近公开资料核验：**2026-09-14**；未使用个人账号实测联网。

:::warning[2026 年网络调整]
学校返修后网络架构已有变化。现教中心公开的无线连接说明发布于 **2024 年**，访客认证说明发布于 **2024 年**；这些资料不能替代 2026 年现场配置。宿舍宽带页保留了 **2026-09-12** 的社区反馈，尚未取得相应运营商官方套餐与参数说明。

遇到网络名、认证或地址与旧说明不一致时，先核对[现教中心通知](https://xjzx.shou.edu.cn/)，咨询 **021-61900099**，不要反复套用旧配置。
:::

## 账号激活与密码找回

学校[统一身份认证服务说明](https://xjzx.shou.edu.cn/2019/0428/c12948a243958/page.htm)介绍，师生账号在相关学籍、人事信息导入后生成，账号名为学工号，新账号须激活。新生以当年报到通知中的激活入口为准。

忘记密码时，从[网上办事大厅](https://portal.shou.edu.cn/)登录页点击「忘记密码」。没有绑定安全手机或安全邮箱的学生，请联系辅导员提交「统一身份认证密码重置」流程；教职工联系本单位办公室。来源：[官方密码找回说明](https://xjzx.shou.edu.cn/2019/1012/c12937a253582/page.htm)（页面日期 **2020-09-17**），咨询电话 **021-61900238**。

## 访客无线网络

[2024-03-05 访客认证说明](https://xjzx.shou.edu.cn/2024/0305/c12937a326802/page.htm)面向临港校区的校外用户：校内用户从办事大厅搜索「校园网自助服务」，或访问[访客服务](https://guest.shou.edu.cn/)，进入「访客管理」生成邀请码，设置人数和时长后交给来访者。该说明指定访客连接 **`GUEST`** 信号并输入邀请码。

访客可访问互联网，但不因此获得校内信息系统权限。另一份 2024 年无线说明仍列有 `ishou_guest`，如现场信号不同，应向现教中心确认适用入口。

## 在其他高校使用 eduroam

学校于 **2025-01-14** 发布 [eduroam 使用指南](https://xjzx.shou.edu.cn/2025/0114/c12937a337553/page.htm)。本校师生在提供该服务的地点连接 `eduroam`，账号格式为 **学号或工号加 `@shou.edu.cn`**，密码为统一身份认证密码；具体设备配置见官方图文说明。该后缀用于网络漫游认证，不能据此推断个人邮箱地址。

## 校外访问 VPN

校外使用校内公共资源时，可进入 [上海海洋大学 VPN](https://vpn.shou.edu.cn/)，通过学校统一身份认证登录。人脸采集的校外访问步骤见下方；账号或连接问题可通过[信息中心联系方式](/contact/#信息中心-网络、邮箱与信息系统)咨询。

来源：[2026 级新生报到指南](https://mp.weixin.qq.com/s/Ij-n7Y8YEUuHfKWTxkcUuA)；**2026-09-12** 按维护者提供的正文核对入口及认证方式，未测试登录或客户端配置。

### 访问教务、图书馆等校内资源

现教中心的 [VPN 使用说明](https://xjzx.shou.edu.cn/2019/1012/c12937a253578/page.htm)（**2019-10-12**）给出了通用步骤：在校外从学校 VPN 页面下载适合系统的 EasyConnect，服务器填 `https://vpn.shou.edu.cn`，使用统一身份认证登录，连接成功后再打开目标系统；用完后退出连接。

该说明指出校园网内不支持 VPN 登录及客户端下载。因 2026 年宿舍网络调整，本页不能据此判断某个宿舍出口属于哪种网络；连接异常时向现教中心提供当前接入方式咨询，系统问题电话 **021-61900245**。

如果只需访问学术数据库，可先查看 [CARSI 说明](https://xjzx.shou.edu.cn/2025/0114/c12937a337554/page.htm)（**2025-01-14**）：支持 CARSI 且学校已有访问权限的资源，可在「机构登录」或「校外登录」选择上海海洋大学，以统一身份认证访问，无需先连接 VPN。具体数据库范围以[图书馆](https://library.shou.edu.cn/)为准。

### 人脸采集使用 EasyConnect

[新生入校与人脸采集操作指南](https://mp.weixin.qq.com/s/UdDRp1-35VbvNGGtSwkiew)说明，校外办理人脸采集时：

1. 按原文图文指引下载安装 **EasyConnect**，服务器地址填写 **vpn.shou.edu.cn**。
2. 使用学校统一身份认证账号和密码登录。首次使用须先激活账号，原文提供的[账号激活入口](http://authx-service.shou.edu.cn/active-account)为 `http://authx-service.shou.edu.cn/active-account`。
3. VPN 连接成功后，回到「上海海洋大学」公众号，选择 **我的海大 → 人脸采集**，按[人脸采集说明](/service/face-registration/)办理。
