# 校园卡与学生证

校园卡和学生证是两种不同的证件。本页面向在校学生，补充校园卡的办理入口；下方保留纸质学生证的外观介绍。

:::info[信息范围]
最近核验：**2026-09-14**。以下补卡信息来自学校 **2025-06-03** 的公开通知；未现场操作设备。卡面和证件外观保留本手册原有说明，实际以本人领取的版本为准。
:::

## 丢卡或卡片不能使用时

1. 从[网上办事大厅](https://portal.shou.edu.cn/)查看一卡通查询服务。官方[统一身份认证服务说明](https://xjzx.shou.edu.cn/2019/0428/c12948a243958/page.htm)列有一卡通查询系统，但本次未核实在线挂失功能；丢卡时请尽快联系卡务服务，确认当前挂失方式。
2. 学生补卡可查看[关于启用学生一卡通自助补卡机的通知](https://hqc.shou.edu.cn/2025/0603/c9783a341260/page.htm)及其「操作说明及位置图」附件。该通知公布的两处设备位置为：**图文信息中心一楼南门、第一食堂一楼西门**。
3. 按设备提示操作。设备故障或补卡疑问拨打 **021-61900222**，说明设备位置、故障现象及发生时间。

学校通知称设备于 **2025-06-03** 开始试运行；2026 年校园施工期间，位置、通行和可用状态以现场及后勤最新通知为准。

:::warning[费用、余额与充值仍需确认]
现有公开通知未明确当前补卡费用、挂失等待时间、旧卡余额转移时间和所有充值渠道，本页不沿用往届手册里的金额或天数。支付前核对设备提示；充值后余额未更新时保留交易凭证，向卡务服务核查，避免重复支付。
:::

## 申领与申请表

新生领取时间、地点按学院当年报到安排确认。需要办理个人或批量申领业务的，可从[学校后勤服务事项](https://xxgk.shou.edu.cn/xxglhqfwsx/list.htm)查找校园一卡通申请表（条目日期 **2023-09-15**），由受理部门确认适用对象和所需材料。

## 校园卡

校园卡是在校学生最常用的设施。其承担着饭卡、宿舍大门门禁卡、校园大门门禁卡的用途，在部分设备验证学生身份，或是需要证明学生身份时候也会用到。

其肉眼可读身份信息全部位于正面。

正面左侧为入学报道时提交的正面免冠证件照。正面右侧为三行学生信息，依次为学号、姓名和学院。

## 学生证

:::warning[注册与优惠办理]
本次未核实学校现行学生证注册、补办和火车票学生优惠资格办理流程。以下为旧版证件外观介绍，不能作为办理依据；办理前请向学院确认本学期安排，并按铁路官方要求核验优惠资格。
:::

与通常认知不同，学生证是单独的证件。
其封面写有「上海海洋大学」与「学生证」字样，并有校徽图样。
首页左面写有学生证的注意事项，右面则是「勤朴忠实」的校训。

第二页是最主要的信息页，左面有入学报道时提交的正面免冠证件照，并记录有学生学号、姓名。
右面写有学院、专业、性别、生源地、出生日期、入学日期、发证日期与学制。

第三页是注册记录。有对各年度学期的注册日期和注册印章。

第四页也是假期火车票减价优待。一般新生入学的时候班委会告知，提交相应信息即可。

最后一页左面，写有学校记载事项。有临港校区的邮政编码与民星路校区的邮政编码，以及学校官网地址。右面则是火车优惠卡的贴卡处（如有）。
