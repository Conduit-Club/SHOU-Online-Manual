# 教育邮箱福利

学校教育邮箱除了用于校内通信，也可以作为学生身份凭证，申请部分软件、开发工具和在线服务的教育优惠。教育邮箱通常只是验证方式之一，能否通过仍取决于服务商对学校、地区、年龄和在读状态的审核。

## 常见福利

| 服务 | 可能提供的教育权益 | 申请入口 |
| --- | --- | --- |
| Office 365  | 在线版 Office 和 OneDrive 等服务。但不含桌面版 | [Microsoft 365 Education](https://signup.microsoft.com/signup?sku=Education) |
| JetBrains | JetBrains旗下软件的教育授权, 仅非商用用途 | [JetBrains Education](https://www.jetbrains.com/zh/student/) |
| GitHub Student Pack | Github Pro, 一年免费.me域名，Digital Ocean 100USD代金券等 | [GitHub Education](https://education.github.com/pack) |
| Autodesk | Autodesk 教育版授权 | [Autodesk Education](https://www.autodesk.com.cn/education/free-software/featured) |
| Tableau for Students | 包含Tableau Desktop和Tableau Prep Builder, 一年有效期但可续费 | [Tableau for Students](https://www.tableau.com/academic/students) |

## 申请建议

1. 使用学校教育邮箱注册，并按服务商要求完成邮箱验证。
2. 如果仅凭邮箱无法通过，准备学生证、在读证明等材料完成身份审核。
3. 留意授权期限，到期后按要求重新验证在读状态。
4. 使用前确认教育授权是否限制商业用途，以及账号、云资源和作品在毕业后的处理方式。

::: warning 注意
优惠项目、额度、适用地区和审核方式可能随时调整，请以申请时的服务商官方页面为准。不要把邮箱密码、验证码或身份材料交给非官方代办方，也不要默认拥有教育邮箱就一定符合资格。
:::
