# 学校已购买的软件

适用对象：需要教学、科研或办公软件的本校师生。最近核验：**2026-09-14**，仅核对学校公开资料，未验证校内下载与激活。

| -------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |

| 学术数据库                             | [CARSI 介绍及登录方法](https://xjzx.shou.edu.cn/2025/0114/c12937a337554/page.htm)，**2025-01-14**，介绍使用统一身份认证访问学校已有权限的资源             | 数据库访问权与桌面软件安装许可不同；具体已购数据库和访问范围请从[图书馆](https://library.shou.edu.cn/)查询     |

## 获取软件前怎么查

1. 登录[网上办事大厅](https://portal.shou.edu.cn/)，查看与软件、资源下载相关的服务；不要直接使用往届转发的激活码、网盘包或旧 FTP 地址。
2. 向[现代信息与教育技术中心](https://xjzx.shou.edu.cn/)咨询当前学校授权。综合服务热线：**021-61900099**。
3. 专业实验课的软件先询问任课教师或实验室管理员，确认许可是否仅限机房、指定设备或特定课程。
4. 下载前确认软件名称与版本、适用身份、个人电脑是否可安装、校外激活条件、有效期以及离校后处理要求，再按学校提供的渠道安装。

:::warning[尚未确认的授权清单]
本次未找到能够证明 2026 年全校师生普遍享有 Windows、Office、MATLAB、Origin、Adobe 等产品许可的现行公开清单。不得因为学校曾经采购、机房已经安装或邮箱带有教育域名，就认定个人设备获得了使用权。

欢迎补充现行官方通知或登录后可公开的产品说明，注明版本、适用对象和授权期限；不要公开序列号或许可证文件。
:::
