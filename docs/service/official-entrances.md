# 🔗海大常用入口总览

刚开始用海大校园服务时，可以先从这里找入口。学校官网把常用系统放在“快速通道”和“站点链接”里；下面按事项分组。

::: warning 先确认入口
本页只整理学校官网公开展示的链接，不代替各部门的通知和办事指南。系统的登录方式、适用对象和具体功能可能变化，遇到问题时请以目标系统和对应部门的最新说明为准。
:::

## 常用入口

### 数字校园与邮件

- [数字校园（原）](https://portal.shou.edu.cn/)：学校官网快速通道中的数字校园入口。
- [邮件系统](https://mail.shou.edu.cn/)：学校官网快速通道中的校内邮件入口。
- [易班](https://shou.yiban.cn/)：用于进入学校官网列出的易班服务和社区入口。

不确定该用哪个系统时，回到[上海海洋大学官网首页](https://www.shou.edu.cn/)查看快速通道。搜索引擎里的旧链接可能已经失效。

### 学习与教务

- [教务处](https://jwc.shou.edu.cn/)：课程、选课、考试、成绩、学籍、培养方案、毕业和表格下载等教务信息的总入口。
- [校历](https://jwc.shou.edu.cn/xl/list.htm)：按学年查看校历及历史版本。
- [图书馆](https://library.shou.edu.cn/)：进入图书馆网站，查找馆藏、数据库和图书馆服务。
- [体质健康查询](https://tyb.shou.edu.cn/)：学校官网“站点链接”中的体质健康查询入口。

教务处首页还列有“学生教务”“课表”“考试安排”“教学大纲”“培养方案”等快速链接。办理前先看当学年通知、规章制度和表格。[教务处](https://jwc.shou.edu.cn/)

### 学生事务与校园生活

- [学生在线](https://xszx.shou.edu.cn/)：学生教育管理、资助、心理健康、就业创业、共青团工作、易班社区和办事指南的入口。
- [后勤管理处](https://hqc.shou.edu.cn/)：后勤服务、学生公寓、餐饮保障、医疗服务、能源服务、失物招领和维修等信息的入口。
- [意见建议平台](https://workflow.shou.edu.cn/infoplus/form/TSFK/start)：学校官网快速通道中的意见建议入口。
- [海大视频](https://www.shou.edu.cn/hdsp/list.htm)：学校官网列出的校园视频栏目。

### 招生、交流与其他服务

- [研究生招生](https://yjs.shou.edu.cn/)
- [留学生招生](https://gjxy.shou.edu.cn/)

申请、报名或提交材料前，先确认页面上的适用对象、截止日期和最新公告。

## 两个校区

学校官网页脚目前列出两个校区地址：

- **临港校区：** 上海市浦东新区沪城环路 999 号
- **军工路校区：** 上海市杨浦区军工路 318 号

前往部门、办理事务或参加活动前，先在通知中确认校区和具体地点。学校官网提供[校园地图](https://www.shou.edu.cn/xydt/list.htm)，后勤管理处也发布过[校园总平图](https://hqc.shou.edu.cn/2024/0822/c9765a333088/page.htm)。

## 如果入口打不开

1. 从[学校官网首页](https://www.shou.edu.cn/)重新进入，不要继续使用来源不明的旧链接。
2. 确认自己查看的是正确校区、身份和学年。
3. 查找对应部门的最新通知或办事指南。
4. 仍无法解决时，通过学校或部门公开的服务渠道反馈。

请不要在 Issue、评论或截图中提交密码、验证码、身份证号或完整个人信息。
