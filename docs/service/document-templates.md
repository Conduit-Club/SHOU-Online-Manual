# 文档模板

本页整理学校公开的表格与模板入口，适用对象见下表。最近核验：**2026-09-14**，已核对发布页及附件入口，未代替学院确认具体业务受理要求。

## 教务表格

发布部门为**教务处**，主要面向本科生。下列日期是官网页面显示的发布日期，不代表模板只适用于该年度；使用时应重新查看当前页面及当学期通知。

| 模板或表格                                               | 用途与适用对象                                               | 发布日期与官方入口                                                                            |
| -------------------------------------------------------- | ------------------------------------------------------------ | --------------------------------------------------------------------------------------------- |
| 本科生毕业论文（设计）相关表格                           | 本科毕业论文（设计）过程材料；格式要求同时遵从学院与导师通知 | **2025-10-29**，[发布页及 RAR 附件](https://jwc.shou.edu.cn/2025/0923/c11315a346266/page.htm) |
| 学生缓考申请表                                           | 本科生申请缓考；是否允许申请及截止时间须同时看办事流程       | **2025-11-05**，[发布页及 DOC 附件](https://jwc.shou.edu.cn/2021/0512/c11315a288156/page.htm) |
| 学生一般事务申请表                                       | 需办理一般教务事务的本科生；先向学院确认该表是否适用         | **2025-11-07**，[发布页及 DOC 附件](https://jwc.shou.edu.cn/2018/1102/c11315a232041/page.htm) |
| 课程免听、成绩复议、复学选课、补办学历（学位）证明等表格 | 相应教务事务申请人                                           | [学生用表目录](https://jwc.shou.edu.cn/11315/list.htm)，按事项选择最新表格                    |

学籍、成绩、毕业等事项可能已转为线上申请。请先查看[教务处办事指南](https://jwc.shou.edu.cn/)及当学期通知，不要把下载并填写表格视为已经提交申请。

## 后勤与信息化表格

- **后勤与基建管理处**：[学校各类后勤服务事项](https://xxgk.shou.edu.cn/xxglhqfwsx/list.htm)列有校园一卡通个人或批量申请表、学生公寓临时住宿申请表、用电额度申请表等，相关条目日期为 **2023-09-15**。适用于对应事项的申请人或经办单位；先确认办理资格和当前表格版本。
- **现代信息与教育技术中心**：[公共电子邮箱申请](https://xjzx.shou.edu.cn/2019/0428/c12950a243964/page.htm)（**2019-04-28**）说明单位邮箱申请材料与审核方式，适用于学院、部门等单位，不是学生个人邮箱的通用申请模板。

## 研究生及课程模板

研究生请从[研究生院](https://yjs.shou.edu.cn/)的培养、学位相关通知及所在学院通知寻找对应材料，不能套用上表的本科论文表格。课程报告、实验报告也应使用任课教师本学期提供的版本。

目前尚未核实可供全校通用的现行研究生论文排版模板或实验报告模板。社区自制 Word、LaTeX、PPT 模板若被收录，应标注「非官方」，并说明适配的学院、专业和年份。

## 下载和提交前

1. 从上面的**发布页**进入附件，保留该页面链接和下载日期，方便后续核对版本。
2. 核对培养层次、学院、业务名称及当学期截止时间；以当次通知指定的附件优先。
3. 按要求保留表格栏目、签名和盖章位置，确认电子件、纸质件是否都要提交。
4. 不要将填有身份证号、成绩、签名等个人信息的成品当作空白模板上传到公开仓库。
