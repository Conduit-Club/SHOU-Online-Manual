# 学号的意义

学号是学校用于识别学生身份的编号。

登录、选课、成绩查询、校园卡或其他校内服务都有可能涉及学号。

::: warning 待核验
上海海洋大学非本科阶段学生的学号的具体编码规则、不同身份的位数和使用范围尚未核实。
如果你能提供学校公开的学号说明，或经核验的脱敏示例，欢迎补充本页。
:::

## 本科生学号

本科生学号长为7位，形如**25XXXXX**.

例如，假定学生张三是**25**届**某某学院**下**1**班的**14**号，则其学号可能是：**2513114**.

- **25**: 第一第二位代表入学年份。**25**即代表25级的学生，2025年入学。
- **13**: 第三第四位通常情况下可以代表**学院下某专业**。但受制于笔者了解不深，无法确定本数值是否第一位有特殊含义。
- **1**: 第五位代表班级。即该专业下的班级。**1**即是一班。
- **14**: 最后两位代表在班级内的学号。**14**即是前文所述班级（一班）的**14**号。

## 研究生学号

相较于本科生的学号，硕士研究生与博士研究生的学号相对很长。计入阶段前缀时共十位，数字部分共计九位。

受制于笔者自身目前仅就读于本科阶段，暂且只提供大致方向。

硕士研究生的前缀为**M**, 相应代表*M*aster. 博士研究生则是代表*D*octor的**D**作为前缀。
一般来说，会形如**M25XXXX123**.

- **25**: 入学年份，同本科生学号
- XXXX: 中间位数尚不清楚含义
- **123**: 推测最后三位可能类似于本科生学号，分别为班级（**1**班）与班级内学号（**23**号）。
