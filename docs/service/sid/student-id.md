# 学号的意义

学号是学校用于识别学生身份的编号。

登录、选课、成绩查询、校园卡或其他校内服务都有可能涉及学号。

## 确认自己的学号与登录账号

学校[统一身份认证服务说明](https://xjzx.shou.edu.cn/2019/0428/c12948a243958/page.htm)（2019-04-28）明确：本科新生信息导入教务系统、研究生新生信息导入研究生管理系统后，会生成对应的统一认证账号，账号名为学工号，新账号需要激活。

- **不知道学号**：先核对学校或学院提供的本人报到、学籍信息；仍无法确认时，联系学院辅导员核实，不按下方示例自行拼出账号。
- **首次登录**：打开[学校统一身份认证](https://uis.shou.edu.cn/cas/login)，按“账号激活”入口操作；账号尚未导入时，向学院确认进度。
- **忘记密码**：通过页面的“忘记密码”入口，按已绑定安全手机的提示找回；无法自助重置的学生，官方说明要求联系辅导员，由其发起密码重置申请。
- **怀疑系统问题**：联系现教中心公开服务热线 **021-61900099**；完整入口说明见[常用入口总览](/service/official-entrances.html)。

## 本科生学号

原手册中的本科生示例长为 7 位，形如 **25XXXXX**。

例如，原示例假定学生张三是 **2025 级**某专业 **1** 班的 **14** 号，将其写为 **2513114**。这是虚构示例，以下字段解释未取得官方编码表确认：

- **25**: 第一第二位代表入学年份。**25**即代表25级的学生，2025年入学。
- **13**: 第三第四位通常情况下可以代表**学院下某专业**。但受制于笔者了解不深，无法确定本数值是否第一位有特殊含义。
- **1**: 第五位代表班级。即该专业下的班级。**1**即是一班。
- **14**: 最后两位代表在班级内的学号。**14**即是前文所述班级（一班）的**14**号。

## 研究生学号

原手册按十位展示硕士和博士研究生学号，并把第一位解释为阶段前缀、后九位解释为入学年份、学院、学专和研究生序号。以下是原有解释，尚未获得覆盖这些字段及适用年份的官方规则证明。

### 硕士研究生

格式为：**M + 年份两位 + 学院两位 + 学专一位 + 研究生序号四位**。

- **M**：硕士研究生的阶段前缀，取自 _Master_；
- **年份两位**：入学年份的后两位；
- **学院两位**：所属学院对应的两位编码；
- **学专一位**：学科专业对应的一位编码；
- **研究生序号四位**：研究生序号，不足四位时按四位保留。

例如，按“25 年入学、学院编码 13、学专编码 1、研究生序号 0123”组成的学号为：**M251310123**。

### 博士研究生

格式为：**D + 年份两位 + 学院两位 + 学专一位 + 研究生序号四位**。

- **D**：博士研究生的阶段前缀，取自 _Doctor_；
- **年份两位**：入学年份的后两位；
- **学院两位**：所属学院对应的两位编码；
- **学专一位**：学科专业对应的一位编码；
- **研究生序号四位**：研究生序号，不足四位时按四位保留。

例如，按“25 年入学、学院编码 13、学专编码 1、研究生序号 0123”组成的学号为：**D251310123**。

## 后续核验需要什么

需要学校公开的学号编制说明、适用年级及编码表，尤其是本科生第 3—5 位、研究生学院和专业字段，以及转专业或培养类别变更时的处理规则。请不要通过公开真实学生名单来猜测规律；修订时提供不含个人隐私的制度或服务说明即可。
