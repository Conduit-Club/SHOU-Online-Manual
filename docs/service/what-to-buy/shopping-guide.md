# 什么值得买

:::info[适用范围]
本页面向**临港校区住校新生**。采购表是生活建议，不是学校必购清单；最近公开来源核验：**2026-09-14**。证件、照片和档案要求请看[新生指南](/freshman-guide/)，研究生、预科生和国际学生按各自入学通知准备。
:::

## 先准备能度过第一晚的物品

| 类别           | 建议携带                                 | 购买前判断                                           |
| -------------- | ---------------------------------------- | ---------------------------------------------------- |
| 床上用品       | 床单、被褥、枕头、枕套                   | 核对床位尺寸、是否已订购学校提供的用品，避免重复购买 |
| 洗漱清洁       | 牙刷、牙膏、毛巾、拖鞋、洗护用品、纸巾   | 初到校可先用小包装，之后按实际消耗补充               |
| 换洗与收纳     | 换洗衣物、衣架、洗衣袋                   | 收纳箱、鞋架等量好柜子和床下空间再买                 |
| 日常出行       | 雨伞、水杯、便于步行的鞋                 | 根据天气与出行习惯选购，不必一次带齐四季衣物         |
| 学习与电子用品 | 手机及充电器、基本文具、已有电脑（如需） | 电脑等大额采购先确认专业软件和课程要求               |
| 个人用品       | 眼镜、个人卫生用品及已有的个人常用药品   | 按本人需要准备，不采用统一药品购买清单               |

后勤[学生公寓介绍](https://hqc.shou.edu.cn/9796/list.htm)给出的床位参考尺寸是 **90 cm × 200 cm**（常设栏目，未标发布日期，2026-09-14 核验）。宿舍正分批维修，床垫、床帘支架仍应以**本人实际床位**为准，先问清再买。

## 到校后和室友商量再买

- **共用清洁用品：** 扫把、拖把、垃圾袋等先检查已有配置，再协商数量、费用和使用规则。
- **饮水设备：** 先问值班室当前开水、桶装水服务，避免重复购买饮水机；见[公寓生活设施](/facilities/#洗衣饮水与公共用品)。
- **空调：** 后勤公寓介绍列有租赁服务。当前是否已装、如何续租、押金和费用分摊须根据本寝室合同及当年通知确认，不套用旧价目表。
- **电器与排插：** 先核对宿舍用电管理要求及公共用品配置，再决定购买。学校[宿舍空调告知书](https://www.shou.edu.cn/2015/0902/c285a183912/page.htm)曾要求宿舍内不得使用其他大功率电器（2015 年历史规定，当前允许范围向宿管确认）。电热锅、电炉、热得快等不列入本页建议清单。
- **打印机、工具和大件设备：** 先使用已有公共服务，再按实际频率决定是否购买。打印见[打印与复印](/service/teaching/printer.html)。

## 购买地点与注意事项

到校后先查看宿舍附近便利店、校外商店的当日商品和价格；门店核验情况见[饮食](/canteen/)。本页不推荐未经核实的商户，不承诺固定价格。

网购前确认[快递收件地址与领取方式](/service/packages/)。大件行李尽量避免过早到站；床品、收纳用品先量尺寸再下单，保存订单和退换货条件。

“学校指定”“新生必须购买”的宣传，应与学校当年通知逐项核对。招生办[2025 年录取进度公告](https://zsjy.shou.edu.cn/2025/0708/c13814a345142/page.htm)提醒：录取材料邮费由学校承担，未委托其他机构发放或出售物品（适用 2025 年录取材料邮寄；2026 年寄送清单按本人通知书核对）。购买床品、手机套餐等服务前，确认销售方及自愿购买条件。
