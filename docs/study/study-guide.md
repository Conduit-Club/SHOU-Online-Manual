# 学习与发展

选课前看学分，学期中找资料，赶论文时找工具。这里分成三个入口：

## 课程、学分与 GPA

[打开课程、学分与 GPA](/study/courses-and-gpa.html)

通识课、公共课、专业课分别是什么？创新创业学分怎么攒、能替代哪些课？以 2025 级计算机科学与技术专业为例，读懂培养方案里的学分分类，再用页面里的 GPA 计算器估算成绩。

## 刷 GPA 实用网站

[打开刷 GPA 实用网站](/study/learning-sites.html)

选课评价、思政练习、学长学姐的期末笔记，以及补课和找书的入口。想找计网、操作系统、软工、编译原理的复习资料，可以从这里开始。

## 发论文实用工具

[打开发论文实用工具](/study/paper-tools.html)

从找文献、读英文到管理引用、排版和校对，按写作环节挑工具。课程论文、实验报告和毕业论文也用得上。

## 学校的消息去哪里找

- [教务处](https://jwc.shou.edu.cn/)：培养方案、选课、考试、成绩和学籍通知。办理前看清学年、学院和适用对象。
- [研究生院](https://yjs.shou.edu.cn/)：研究生培养、学位与招生信息。
- [图书馆](https://library.shou.edu.cn/)：馆藏、借阅、数据库和学习服务。
- [学校官网](https://www.shou.edu.cn/)：学院、科研机构和学校通知。
- [就业信息入口](https://jcxt.shou.edu.cn/)：就业相关信息。

## 具体事项怎么开始

| 你要做什么               | 先准备什么                                 | 下一步                                                                                                              |
| ------------------------ | ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------- |
| 核对毕业或选课学分       | 入学年级、专业方向、本人培养方案与已修课程 | 看[课程、学分与 GPA](/study/courses-and-gpa.html)，再按当学期教务或研究生培养通知核对                               |
| 处理选课、成绩或学籍疑问 | 学院、课程号、学期、具体问题及相关通知     | 联系学院教学管理人员；本科公开渠道见[黄页：本科教务](/contact/#本科教务)                                            |
| 开题、写论文或准备答辩   | 本人培养层次、学院要求和导师提供的材料     | 查看[论文工具](/study/paper-tools.html)及[官方文档模板](/service/document-templates.html)，模板和期限以当次通知为准 |
| 登录失败或忘记密码       | 实际分配的学号、绑定的安全手机             | 查看[学号与统一认证说明](/service/sid/)                                                                             |

内容有缺漏，请按自己年级、专业的最新通知核对。

如果你也有课程笔记或好用的网站，欢迎补充链接、适用课程和资料年份。课程规则与学分要求请附学校来源；个人经验注明适用年级，会更方便后来的人参考。
