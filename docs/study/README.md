# 学习与发展

## 从哪里查

- [教务处](https://jwc.shou.edu.cn/)：校历、课表、考试安排、教学大纲、培养方案、学生教务和教务通知。
- [图书馆](https://library.shou.edu.cn/)：馆藏、借阅、数据库、阅览室和其他学习服务。
- [学校官网](https://www.shou.edu.cn/)：查找学院、研究机构、科研项目和学校通知。
- [就业信息入口](https://jcxt.shou.edu.cn/)：查看学校公开的就业相关信息。

## 办理学习事务时

先确认学年、培养层次、学院和适用对象，再打开教务处发布的通知或系统入口。选课、考试、成绩、学籍和毕业要求都可能按年份调整，页面上的旧经验不能代替当学年的规章和通知。

遇到系统问题时，保存页面、报错信息和操作时间，再向通知中列出的部门或学院教务老师反馈。不要只凭搜索引擎中的旧页面判断当前流程。

## 后续收录

课程经验、学习空间、科研与竞赛信息可以提交；涉及课程规则、成绩计算、学分要求和办事流程的内容，需要附学校或学院的公开来源及核验日期。

通用学习经验可以保留；课程规则、成绩计算和办事流程必须以本校当学年文件为准。
