# 本科培养计划

培养计划是一份「毕业前要完成什么」的清单。它通常按课程类别、课程性质、学分和建议开课学期列出要求；选课时要以自己入学年份、学院、专业和培养方向对应的版本为准。

## 先找到对应版本

上海海洋大学教务处会发布按年级整理的教学一览和相关通知。可以从[教务处网站](https://jwc.shou.edu.cn/)进入教学运行或通知栏目，再按以下顺序筛选：

1. **入学年份**：同一专业不同年级可能使用不同课程名称、学分或毕业要求。
2. **学院与专业**：先确认专业全称；有些专业还分方向或实验班。
3. **培养层次**：本科生、研究生和专升本适用的文件不能混用。
4. **文件版本**：优先使用教务处发布的完整教学一览和当学期选课通知，注意文件发布日期与适用年级。

教务处的[《2025 级教学一览》](https://jwc.shou.edu.cn/2025/0917/c11235a346103/page.htm)就是按年级发布的官方材料。下载后可以先用 PDF 搜索专业名称，再定位到该专业的课程表和毕业要求。

## 读课程表时看这几列

培养计划中的「课程性质」「课程类别」「学分」「学时」「开课学期」各自回答不同问题：

| 项目           | 要回答的问题                 | 选课时的用法                                           |
| -------------- | ---------------------------- | ------------------------------------------------------ |
| 课程性质       | 是必修、限选还是选修？       | 必修课不能用任意选修课替代；限选要按备注凑足指定范围。 |
| 课程类别       | 学分要计入哪一个模块？       | 先补缺少的模块，不要只看总学分。                       |
| 学分与学时     | 这门课占多少毕业要求？       | 记录已修和待修学分，留意理论课与实践环节是否分开。     |
| 建议开课学期   | 通常安排在第几学期？         | 结合先修课、时间冲突和当学期开课情况调整。             |
| 备注与先修要求 | 是否有方向、班级或搭配限制？ | 报名前再次核对选课系统和学院通知。                     |

不同专业的模块名称和学分数并不相同。比如现有[课程、学分与 GPA](/study/courses-and-gpa.html)页面用 2025 级计算机科学与技术专业说明通识、公共基础、学科基础、方向必修、专业选修和实践实训；这些数字不能直接套到其他专业。

## 给自己做一张进度表

拿到对应培养计划后，建议把课程表复制成自己的核对表，至少保留以下信息：

| 信息             | 示例                                         |
| ---------------- | -------------------------------------------- |
| 课程名称与课程号 | 课程名称可能相同，课程号更适合核对成绩记录。 |
| 课程类别与性质   | 通识必修、公共基础、专业选修等。             |
| 要求学分         | 培养计划要求完成的学分。                     |
| 已修状态         | 已通过、修读中、未修或需重修。               |
| 计划学期         | 结合当学期课表和个人时间安排。               |

每次选课前先做三步：

1. **按类别统计缺口**：总学分够了，也可能还缺某个必修模块、美育、实践或创新创业要求。
2. **检查先修关系**：先修课未完成时，不要只按建议学期报名后续课程。
3. **对照当学期开课通知**：培养计划列出的是总体要求，不代表课程每学期都会开设。

课程替代、免修、重修、学分认定和毕业审核都有单独规则。遇到「这门课能不能顶那门课」的问题，应带上本人培养计划、成绩记录和课程号，向学院教学管理人员或教务处确认，并保留当次通知。

## 常见误区

- **把总学分当成唯一条件**：毕业审核还会检查必修课、模块学分和实践环节。
- **照抄其他年级的课表**：课程名称、学分和开课学期可能已经调整。
- **把课程范围当成开课承诺**：最终能否选到要看当学期课程和选课资格。
- **只记课程名称不记课程号**：同名课或方向课容易在成绩核对时混淆。
- **把学长学姐经验当成校规**：经验可用来安排时间，政策和毕业要求仍以官方文件为准。
